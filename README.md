#### SurfCrew School
**Uma escola de surf, uma aplicação de ponta a ponta.**

Projeto individual de desenvolvimento web para gestão de uma escola de surf.

- 🔐 Registo, login e recuperação de palavra-passe
- 🏄 Consulta de horários e inscrição em aulas
- 👤 Área do utilizador e edição de perfil
- ⚙️ Painel administrativo com gestão de aulas e utilizadores
- 🗃️ Base de dados MySQL e acesso através de PDO

**HTML · CSS · PHP · MySQL**
